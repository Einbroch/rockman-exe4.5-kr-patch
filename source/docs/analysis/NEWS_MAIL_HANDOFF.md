## 검증 상태

정상 입력 회귀: 새 게임 초기 설정, 가나 입력 세 페이지의 기능 버튼, 네 내비 선택/확인/취소, 첫 메일23쪽 읽기/목록 복귀/재열기 PASS.
추가 본문은 원래 압축 해제/출력기에서 격리 진단하며, 진단 개입은 ROM에 포함하지 않는다.
현재 ROM의 오피셜32쪽과 뉴스22쪽 전부 직접 화면을 확인했다. 진행 화살표 겹침 없이 표시, 순서대로 native keyWait, 전체 해제 데이터 일치, 종료 후 목록 복귀 PASS.
진단은 실제 로더 해제 후 원래 스크립트 표 읽기 한 번만 격리 alias한다. 원래 뉴스 `callBeginStoryQuest` 명령은 보존하며 격리 세션에서 실행된다.
진단의 발신자/제목은 첫 I.P.C. 메일의 것이므로 해당 본문의 실제 제목 연결이나 정상 수신·퀘스트 시작/완료 증거가 아니다.
진단 체크포인트는 `diagnostic_checkpoint.mss`이며 정상 플레이 상태로 사용하지 않는다.
검증 파일 `analysis/news_mail_v1/runtime_verification.json`, 화면 `poc/runtime/news-mail-v1-*`.
입력/ID 변조 거부 포함6tests PASS, 관련 Python 컴파일 PASS.
