# 첨부 화면 미번역 후속 목록

2026-10-12 사용자가 첨부한 12장 기준이다. 이번 요청에서 우선 반영하는 것은
메인 메뉴 세 번째 `どにちのたいかい` → `주말 대회`이다.
아래는 첨부 당시 관측이다. 후속 `startup_ui_v1_r7`의 반영/검증 현황은 표 아래에 기록한다.

|---|---|---|
| 1 | 초기 날짜·시각 | 입력 안내, 요일 `(土)`, 증감·다음·뒤로 조작 안내 |
| 2 | 날짜 확인 | `これでよろしいですか?`, `はい`, `いいえ` |
| 3 | 첫 실행 인사 | PET 구매 감사 안내, 사용자 이름 입력 안내 |
| 4 | 이름 입력 | 이름 질문은 한글이나 실제 글자판과 전환·뒤로·결정 라벨은 일본어. 자동 한글 입력·저장 미완성 |
| 5·8 | 성별 | `せいべつを えらんでください`, `おとこ`, `おんな` |

이 목록은 화면 증상에 근거한 후속 조사 대상이며 ROM 주소, 저장 형식, 렌더러,
원인이나 완료를 확정하지 않는다. 각 항목을 실제 consumer에 연결한 다음
텍스트/픽셀 번역, 실제 표시 및 입력·저장 경로 검증을 수행해야 한다.

사진의 플레이어 이름 사각형은 단순 미번역과 별개로 표시 문제일 가능성이 있어
추후 원래 입력값·저장 바이트·폰트 공급을 대조한다. 사용자 세이브는 수정하지 않는다.

## 후속 실제 ROM 확인

`poc/output/exe45_ko_development_startup_ui_v1_r7.gba`에서 일반 버튼 입력으로 새 게임을 진행했다.
텍스트 52개를 추가 반영하고 PET 안내/날짜 버튼 이미지도 적용했다.

- 1: 날짜·시각 입력 안내, 요일과 늘림·줄임/다음/뒤로 그래픽을 한글로 확인.
- 2: 날짜 확인 질문과 예/아니요 한글 표시 및 예 선택 진행 확인.
- 3: PET 구매 감사·이름 입력 요청 이미지 한글 표시. 압축 해제된 전체 타일/맵이 실제 VRAM/EWRAM과 일치.
- 4: 이름 질문만 기존 한글. 가나 입력판과 기능 버튼은 아직 일본어; 자동 조합/한글 저장 미구현.
- 5~10: 성별, 나이, 직업 열 가지, 프로필 확인 질문/항목/선택지를 한글로 확인. 정상 입력한 일본어 이름 `あ`는 실제 재표시되어 이번 정상 경로에서 사각형 증상은 재현되지 않았다. 사용자 저장 파일의 사각형 원인까지 확정한 것은 아니다.
- 11: `내비 록맨 / 선택할까요?` 및 예/아니오 한글 확인. 동적 이름 롤·거츠맨·넘버맨은 ROM 반영/정적 검증만 수행. NAVI SELECT 제목 및 카드 그림 글자는 아직 원본.
- 12: 록맨 `메일이야!!` 한글 확인. 원래 동적 별명/호칭은 그대로 보존되어 `あくん`이 표시된다.

완료 증거: `poc/runtime/startup-ui-v1-r7-verification.json`.
전체 초기 메뉴/게임/한글 입력의 완료 선언이 아니다. 입력 자판과 내비 카드 그래픽이 후속 대상이다.

실제 페이지 전환·재진입·일본어 `い` 입력 및 프로필 확정/재표시 확인. 가나 글자판은 아직 그대로이며 한글 입력/저장 구현은 아니다.
