# 공유 키 아이템 메시지: 번역 초안 및 로더 추적

후속 작업: 빈 안내1개를 메모리 증가 없이 적용하고 정상 화면 검증을 완료했다.
현재 상태는 `KEYITEM_EMPTY_ROM_HANDOFF.md` 참조. 아래는 ROM 반영 전의 보존된 조사 기록이다.

상태: 개발 초안 / 배포 불가 / **이번 작업의 ROM 반영 없음**.
기존 검증 ROM은 `poc/output/exe45_ko_development_gutsman_calendar_inventory_v1.gba` 그대로 보존했다.
SHA-256: `2adcc7111363c377628071f9b3ac313ead4615c157a7478f842c316a410a80d1`.

## 번역 작업

`analysis/keyitem_translation_draft_v1/draft.json`에 709408의 전체 39개 원문 리터럴을 번역했다.
견습/대회 라이선스, 열쇠, 수량 표시가 있는 아이템 설명, 빈 소지품 안내, 메모리, 회복/보조 아이템을 포함한다.
모든 문구는 needs_review이며 용어와 동적 수량 포함 레이아웃 검토가 남았다.
각 리터럴의 줄바꿈 수, 수량 출력 명령, 컨트롤 구조를 보존했다.
화자 없는 공유 메시지에는 거츠맨 말투를 적용하지 않았다.
초안은 기본 빌드 입력이나 번역 완료 집계에 추가하지 않았다.

## 새 런타임 증거

`poc/runtime/keyitem-loader-v1-enter`는 동일 ROM의 검증된 select-gutsman 체크포인트에서
일반 입력 `none:1:7,left:2:90,a:2:90`으로 진입했다. ROM/RAM/게임 진행 값을 수정하지 않았다.
화면 `step_003.png`는 여전히 일본어인 원본 안내 화면이다. 한국어 표시 성공 증거가 아니다.

네이티브 BIOS LZ77 래퍼 080EC158 호출 시 다음 값을 직접 관측했다.

- 소스 08709408, 목적지 02020800, LR 080349F1.
- 실제 함수 080349DC의 080349E8/080349EA PC 상대 로드가
  리터럴 08034A2C(소스)/08034A30(목적지)를 읽는다.
- 소스 전체 해제 결과 1,291바이트가 실제 EWRAM에 정확히 일치한다.
- 다른 참조 0804C5E8은 별도 함수 0804C5B4의 02031000 목적지 경로다.
  이번 경로에서는 해당 소비자에 진입하지 않았다.

`analysis/keyitem_translation_draft_v1/loader.json`에 원본/ROM/증거 해시와 미해결 경계를 기록했다.
소스 주변 데이터 풀을 코드로 역어셈블한 결과는 실행 증거로 채택하지 않았다.

## 컴파일 벤치

`tools/bench_keyitem_translation.py`의 독립 벤치는 ROM을 만들거나 수정하지 않는다.
원본의 바이트 동일 재컴파일, 한국어의 리터럴/명령 의미 역변환, 재컴파일 바이트 동일성,
literal-only LZ10 자체 및 독립 디코더 역변환을 검증했다.

| 범위 | 해제 후 바이트 | 원본 대비 | 저장 바이트(literal-only) |
|---|---:|---:|---:|
| 원본 | 1291 | 0 | 1460 |
| 빈 아이템 안내만 | 1318 | +27 | 1488 |
| 39개 전체 초안 | 2477 | +1186 | 2792 |

이 표의 압축 검증은 벤치 검증이며 대상 게임 소비자 호환성은 아직 검증하지 않았다.
압축기의 포맷 한계 0xFFFFFF는 런타임 버퍼 크기가 아니다.

## 재개 지점

1. 02020800 UI 및 02031000 별도 소비자의 실제 버퍼 용량/수명/공유 메모리 사용을 확인한다.
   인접 리터럴 02021000의 존재만으로 경계를 단정하지 않는다.
2. 전체 2477바이트가 불가능하면 빈 안내 1318바이트 부분 적용과 전체 재배치 옵션을
   실제 메모리 경계로 비교한다. 다른 소비자의 포인터를 무조건 함께 바꾸지 않는다.
3. 두 소비자의 경계를 설명할 수 있을 때만 원본 기반 누적 빌드에 등록한다.
4. 압축 해제 결과 전체 일치, 실제 한글 글리프/픽셀, 닫기/재진입/인접 메뉴 및
   기존 저장/불러오기 회귀를 검증하고 새 ROM/해시를 전달한다.

추가 테스트: `python -X utf8 -m unittest discover -s tools -p test_keyitem_translation_draft.py` 4개 PASS.
전역 미완료 조건인 한글 입력/편집→저장 레코드→모든 재표시→새 실행 영구 저장 재로딩→
기존 세이브 호환성은 여전히 열려 있다. 이 국소 번역/로더 조사는 이를 해결하지 않는다.
