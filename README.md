# 록맨 에그제 4.5 리얼 오퍼레이션 한글패치 (개발판)

GBA 『ロックマンエグゼ4.5 リアルオペレーション』 비공식 한글패치입니다. **완성본이 아닌 개발판**입니다.

패치 파일은 [Releases](https://github.com/Einbroch/rockman-exe4.5-kr-patch/releases)에서 받을 수 있습니다. 이 저장소에는 ROM이 들어 있지 않습니다.

## 적용 대상

일본판 무패치 원본 `Rockman EXE 4.5 Real Operation (J)`

| 항목 | 값 |
|---|---|
| 원본 크기 | 8,388,608바이트 |
| 원본 SHA-256 | `588a77da006fb0dca0c8addbcc316d7bd4b1c3a42db24750bcfe17b170ac5ef8` |
| 적용 후 SHA-256 (v0.9.1) | `211d3cca83a1fd5dcc03055663566724d2c209d6ba72d697952e08d4e67cc188` |

BPS(Floating IPS)와 xdelta 두 형식을 제공합니다. 결과는 같으니 둘 중 하나만 원본에 적용하세요. 자세한 적용 방법은 릴리즈 zip에 든 `README.ko.md`를 보세요.

## 들어 있는 것

- 번역 단위 30,359개: 대사, PET·내비 대화, 메일, 토너먼트, 서브칩·장비 문구, 메뉴·지역명 라벨
- **한글 자판**: 이름·프로필 입력에서 자음·모음을 누르면 음절이 자동으로 조합됩니다. 세이브 후 다시 켜도 한글 이름이 유지됩니다.
- 그림 글자 일부: PET 메뉴·하위 화면 제목, 전투 결과 창, 내비 대화 주제 말풍선, 필드 시계, 날짜 입력 화면 등

## 알려진 한계

- 달력 일정 이름은 아직 한글로 입력할 수 없습니다.
- 번역 초안 일부(187개)와 일부 그림 글자는 아직 일본어입니다.
- 이름·별명은 한글 4자 이하라고 가정하고 조판했습니다. 더 길면 일부 대사가 창 밖으로 넘칠 수 있습니다.
- 격리 에뮬레이터로 초반 진행과 주요 화면만 확인했습니다. 전체 플레이, 실기, 통신 기능은 검증하지 않았습니다.

## 작업 소스

[`source/`](source/)에 빌드·검증 도구(Python), 한국어 번역 파일, 작업 기록이 있습니다. ROM이나 ROM에서 뽑아낸 그래픽 데이터는 들어 있지 않습니다.
